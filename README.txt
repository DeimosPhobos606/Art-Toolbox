Art Toolbox 0.1

1. Распакуйте архив целиком.
2. Откройте Art_Toolbox.html в браузере.
3. Выберите инструмент на главной странице или на верхней панели.

Не перемещайте файл запуска отдельно от папки tools.
Исходные Palette Lab 0.2 и Texture Baker 0.3 сохранены без изменений.
При переключении вкладок инструменты остаются загруженными. Перезагрузка страницы закрывает текущие рабочие сессии; сохраните необходимые результаты заранее. Старые локальные пресеты браузера могут не перенестись автоматически при смене пути к HTML-файлу.
Облачная синхронизация не подключена.
