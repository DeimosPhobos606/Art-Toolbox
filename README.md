# Art Toolbox

## [Открыть Art Toolbox — актуальная версия](https://deimosphobos606.github.io/Art-Toolbox/workspace.html)

**Art Toolbox 0.4.3 Beta** — единая рабочая среда для игровых ассетов: Asset Library, Palette Lab, Texture Baker и Material Lab.

Прямой адрес: https://deimosphobos606.github.io/Art-Toolbox/workspace.html

[Старая автономная версия](https://deimosphobos606.github.io/Art-Toolbox/)

Навигация: Управление проектами и Toolbox. Настройки → Show Tooltips включает подсказки после 2 секунд наведения.

Инструменты доступны без создания ассета. В свободном режиме демонстрационные и импортированные ресурсы общие между вкладками, и сохраняются при явном сохранении Workspace. Без явного сохранения временные данные могут исчезнуть при перезагрузке.

Проекты сохраняются локально в браузере. Яндекс Диск: ручные полные снимки Workspace через OAuth. Для переноса и резервного копирования ассетов используется формат `.artasset`.

## Правило публикации

При выпуске обновлений сохранять постоянную ссылку на актуальную рабочую среду в начале README; при изменении адреса обновлять её одновременно с релизом.

## Яндекс Диск

1. Создать приложение для доступа к API на https://oauth.yandex.ru/client/new/ с разрешением `cloud_api:disk.app_folder`.
2. В Art Toolbox открыть «Яндекс Диск», ввести Client ID, нажать «Получить токен». Скопировать OAuth-токен или адрес ответа OAuth в поле подключения. Client Secret не нужен. Токен хранится в памяти до закрытия страницы.
3. Нажать «Сохранить всё на Диск» и дождаться подтверждения размера снимка. На другом компьютере подключить тот же аккаунт и OAuth-приложение, выбрать снимок, восстановить.

Каждая загрузка создаёт отдельный файл в папке приложения, не перезаписывая предыдущие. Включены проекты, модели, ревизии, сессии инструментов, свободный режим и пользовательские палитры. При восстановлении сохраняется локальная копия прежнего состояния. При блокировке API скачайте полный Workspace (.atworkspace) и перенесите вручную. Интеграция API ещё требует проверки с реальным токеном и в рабочей сети.

## Импорт моделей

OBJ, GLB и FBX доступны в библиотеке, Palette Lab, Texture Baker и Material Lab. FBXLoader Three.js r180 хранится локально в репозитории и загружается только при импорте FBX. Импортируются геометрия, UV0 (включая смещённые UV), нормали, имена мешей, трансформации и идентификаторы материалов. Анимации, скелетные деформации и текстуры FBX не импортируются; Material ID пока не используется интерфейсом для назначения отдельных материалов. Экспортируйте статическую модель с UV.

## Сохранение и удаление

Кнопка «Сохранить» рядом с Яндекс Диском сохраняет весь Workspace на Диск при подключённом OAuth; без подключения сохраняет локально, включая свободный режим. Зелёный цвет означает подтверждённое сохранение, янтарный — изменения после него. При закрытии вкладки с изменениями браузер показывает системное предупреждение (на мобильных устройствах не гарантируется); в Настройки → Завершить работу доступен собственный диалог. Ctrl+S также сохраняет Workspace в главном окне. Удаление проекта, ассета и ресурса выполняется с подтверждением, с очисткой ревизий и относящихся к ним сессий/ссылок. Старые резервные снимки не удаляются.
