# Art Toolbox

## [Открыть Art Toolbox — актуальная версия](https://deimosphobos606.github.io/Art-Toolbox/workspace.html)

**Art Toolbox 0.3 Beta** — единая рабочая среда для игровых ассетов: Asset Library, Palette Lab, Texture Baker и Material Lab.

Прямой адрес: https://deimosphobos606.github.io/Art-Toolbox/workspace.html

[Старая автономная версия](https://deimosphobos606.github.io/Art-Toolbox/)

Навигация: Управление проектами и Toolbox. Настройки → Show Tooltips включает подсказки после 2 секунд наведения.

Инструменты доступны без создания ассета. В свободном режиме демонстрационные и импортированные ресурсы общие между вкладками, но хранятся только до перезагрузки страницы.

Проекты сохраняются локально в браузере. Яндекс Диск пока не подключён. Для переноса и резервного копирования ассетов используется формат `.artasset`.

## Правило публикации

При выпуске обновлений сохранять постоянную ссылку на актуальную рабочую среду в начале README; при изменении адреса обновлять её одновременно с релизом.

## Roadmap

- Texture Baker 2.0 — новый знаковый лучевой Curvature по нормалям, CPU/GPU; проверка на реальных моделях и GPU предстоит.
- Material Lab 0.2 — провода, миниатюры, масштабирование, дополнительные ноды и каналы, JSON-пресеты. Полноценный PBR-просмотр пока не реализован.
- Глобальная библиотека ресурсов.
- Яндекс Диск.
- Общий вьюпорт — после Яндекс Диска.

Формат проектов не изменён. Карты предыдущих версий не пересчитываются автоматически.
